# Rakeesh Kumar — Portfolio

A responsive personal portfolio landing page built with React and Vite.

## Run locally

```bash
npm install
npm run dev
```

Create a production build with `npm run build`.

## Personalize

Update the intro and work copy in `src/App.jsx`. Replace the GitHub profile URL with your preferred contact or social link if needed. The work cards are illustrative examples rather than published case studies.
